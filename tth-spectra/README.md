# tth-spectra : Spectral and Dynamic Analysis (Python)

`tth-spectra` studies the asymptotic iterative behavior of the Thutmos Transformation.

## ⚙️ Features

* **Contracting regime**: Visualization of the geometric convergence towards the attractor center $P_\infty$ dictated by the Banach fixed-point theorem.
* **Isometric regimes**: Generation of periodic orbits when the rotation angle is rational ($\rho(\theta) \in \mathbb{Q}$); and generation of dense quasi-periodic orbits on an invariant circle when the angle is irrational ($\rho(\theta) \notin \mathbb{Q}$).
