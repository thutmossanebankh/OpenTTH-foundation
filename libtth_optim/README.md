# libtth-optim : Geometric Optimization (Python/SciPy)

`libtth-optim` demonstrates the interoperability of the C++ core `libtth-diff` with classical numerical optimization algorithms.

## ⚙️ Features

* Use of heuristic optimizers (Black-Box / Nelder-Mead) to search for the optimal spatial configuration minimizing the geometric entropy or the classification loss.
* Proves that the Thutmos Transformation theory can be used without an explicit mathematical gradient to solve complex dynamical systems.
