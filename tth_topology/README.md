# tth-topology : Bundles and 3D Deformations (Python)

This module extends the algebraic structure of the TTH to the three-dimensional space $\mathbb{R}^3$.

## ⚙️ Features

* Application of deformation fields via the special orthogonal group $SO(3)$.
* Simulation of the deformation of a solid (an abstract cube), transforming its straight edges into curves and its flat faces into manifolds.
* Illustration of the fibration of the geometric space $\mathcal{M} = \bigcup_i \mathcal{F}_i$, where each fiber is woven by the influence of a focus.
