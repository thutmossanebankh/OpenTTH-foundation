# tth-neural : Multi-centric Deep Learning (PyTorch)

`tth-neural` connects the Riemannian geometry of the TTH to deep neural networks. It uses spatial attractors to "unfold" non-linear latent spaces.

## ⚙️ Features

* Custom `TTHLayer` layer integrated with PyTorch autograd.
* Geometric parameters (coordinates of the centers $O_i$, spectral angles $\theta_i$) become weights learnable by the AI.
* Resolution of non-linear classification problems through spatial geometric deformation rather than by stacking classical dense layers.
